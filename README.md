# vibe-leadgen — бот, который ищет тебе клиентов для вайбкодинга

Бот сам находит **местные бизнесы без сайта** (парикмахерские, автосервисы,
стоматологии, кафе…), оценивает их «жирность», готовит **персональный текст**
под каждого и присылает тебе карточку с телефоном и кнопкой «Написать в Telegram».
Отправляешь вручную одним кликом — без автоматического спама.

Дополнительно бот ищет в интернете людей, которые прямо пишут «нужен сайт»,
и прикладывает их посты к утренней подборке.

---

## Как это работает

```
OpenStreetMap (Overpass API, без ключа)  ┐
Яндекс «Поиск организаций» (опц., ключ)  ├─► дедупликация ─► скоринг 0-100 ─► персональный текст
DuckDuckGo («нужен сайт» из интернета)   ┘         (SQLite)      «жирные»        (3 варианта)
                                                                   │
                                            TG-бот: карточка лида с кнопками
                                            ✈️ TG · 🗺 Карты · 📄 Текст · ✅ Отправил
```

- **«без сайта»** проверяется прямо в запросе к базе: бизнесы, у которых есть
  тег `website` / `url` / `contact:website`, отбрасываются.
- **Скоринг «жирных»** (0-100): вес ниши (стоматология 42 → сервисы 24),
  есть телефон +25, часы работы +12 (живой бизнес), город-миллионник +8,
  оформленный бренд +5. В карточке всегда написано, почему лид приоритетный.
- **Персональный текст**: подставляются название, город и выгода ниши
  (для салона — онлайн-запись, для автосервиса — запись и прайс). Никакой воды
  и выдуманных фактов — честное наблюдение «сайта нет» и оффер с демо до оплаты.
- **Дедуп**: всё складывается в SQLite (`data/leads.db`), одни и те же бизнесы
  не приходят дважды — ни между запусками, ни между источниками (сверка по телефону).

## Установка (5 минут)

Нужен Python 3.10+ (на Windows — галочка «Add Python to PATH» при установке).

1. Скачай папку `leadgen-bot` целиком в любое место.
2. Открой терминал в этой папке и поставь зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Получи токен бота: в Telegram открой [@BotFather](https://t.me/BotFather)
   → команда `/newbot` → придумай имя → скопируй токен вида `123456:AA...`.
4. Вставь токен в `config.json` в поле `bot_token`.
5. Поменяй `city_main` на **свой город** и добавь `satellites` — города-сателлиты,
   например:
   ```json
   "city_main": "Казань",
   "satellites": ["Зеленодольск", "Волжск"]
   ```
6. Запусти:
   - Windows: двойной клик по `start.bat`
   - Linux/macOS: `./start.sh`
   - или просто `python bot.py`
7. В Telegram открой своего бота и нажми **/start** — бот привяжется к тебе
   (он приватный, другие им пользоваться не смогут).

```

📍 Казань, ул. Ленина, 5
⏰ Mo-Fr 09:00-19:00
📞 +79870001122
📝 Готовый текст (вариант 1/3): Здравствуйте! Пишу по поводу «Алтынчеч» (Казань)…
```

Кнопки:
- **✈️ Написать в Telegram** — открывает чат с номером (`tg://resolve?phone=…`).
  Работает, если номер привязан к TG и человек не скрыл его настройками
  приватности. Если не сработало — скопируй номер из карточки и добавь
  в контакты: Telegram покажет, есть ли у него аккаунт. Это ограничение
  самого Telegram, его никто не обходил иначе.
- **🗺 Найти на Яндекс.Картах** — проверить бизнес глазами перед отправкой.
- **📄 Текст отдельно** — присылает текст отдельным сообщением, чтобы удобно копировать.
- **🔄 Другой текст** — перегенерировать: всего 3 варианта (тёплый / деловой / через выгоду).
- **✅ Отправил / ⏭ Пропустить** — помечает лида, в `/стата` видна конверсия.

## Авто-поиск по расписанию

`schedule_enabled: true` и `schedule_hour: 9` — каждый день в 09:00 бот сам
пробегает по городам и нишам из config и присылает утреннюю подборку:
топ-8 приоритетных лидов (`leads_per_digest`) + до 3 заявок из интернета.
Компьютер с ботом должен быть включён (или оставь бота на самом дешёвом VPS —
там он будет работать 24/7).

## config.json — все поля

| Поле | Смысл |
|---|---|
| `bot_token` | токен от @BotFather |
| `sender_name` | подпись в конце сообщений, например `"Артём"` (пусто — без подписи) |
| `city_main` | главный город |
| `satellites` | города-сателлиты списком |
| `niches` | какие ниши искать: health, auto, beauty, food, sport, edu, services |
| `schedule_*` | время утреннего авто-поиска |
| `leads_per_digest` | сколько карточек за одну подборку (не ставь 50 — это спам и выгорание) |
| `min_score` | порог приоритетности 0-100 (по умолчанию 40) |
| `require_contact` | показывать только тех, кому есть чем написать |
| `web_intake` / `web_queries` | искать «нужен сайт» в интернете и по каким запросам |
| `yandex_api_key` | опционально: ключ «Поиска организаций» с developer.tech.yandex.ru — добавит точные данные Яндекс.Карт |
| `overpass_mirrors` | доп. зеркала Overpass, если основные не отвечают |
| `extra_scoring` | переопределение весов скоринга, например `{"phone": 30}` |

## Источники и честные ограничения

- **OpenStreetMap** — основной источник. Бесплатно, легально, без ключа.
  Полнота зависит от региона: в крупных городах данных много, в маленьких
  может быть негусто. Комплементарно проверяй лида по кнопке «Карты».
- **Яндекс.Карты**: официальный «Поиск организаций» подключается своим ключом
  (`yandex_api_key`). Прямой парсинг Яндекс.Карт бот не делает — Яндекс это
  блокирует и запрещает условиями; официального бесплатного bulk-API у них нет.
- **Заявки из интернета** ищутся через DuckDuckGo. Иногда DDG режет автоматические
  запросы — тогда бот просто не прикладывает этот блок, остальное работает.
  Проверить, что доступно с твоего компьютера: `python cli.py doctor`.
- **Telegram по номеру**: см. выше про кнопку ✈️ — гарантий нет, это приватность TG.

## Этика и закон

Бот ищет открытые данные и готовит **персональные** сообщения, а отправляешь их
ты сам, руками, конкретному бизнесу — это обычный холодный аутрич. Чтобы не
скатиться в спам: один человек — одно сообщение, без рассылки одинаковых текстов
спискам, без автоматических ботов в чужих чатах. Если заказчик просит — сразу
удали его из базы (`⏭` или `/экспорт` → пометь «junk»).

## CLI (без бота, для консоли)

```
python cli.py search --city Казань --niche beauty --top 10
python cli.py search --all-cities --top 20
python cli.py intake            # заявки из интернета

python cli.py serve-site         # живой режим: сайт самообновляется каждые 20 сек
python cli.py auto               # ПОЛНАЯ автоматизация: сам ищет + живой сайт (без Telegram)
python cli.py selftest          # проверка всего конвейера без сети (фикстура)
python cli.py doctor            # какие источники доступны с твоего компьютера
```

## Полная автоматизация (руками ничего делать не нужно)

| Что хочешь | Что запускаешь | Что происходит |
| --- | --- | --- |
| Просто сайт с автопоиском | **auto.bat** (один клик) | Откроется сайт, бот сам ищет лидов каждые 60 мин и сам пополняет ленту. Окно сверни и забудь. |
| То же + Telegram-бот | **start.bat** + **start_site.bat** | Бот ищет при старте, фоном каждые 60 мин и утром по расписанию, шлёт подборку в Telegram и сам обновляет сайт. |
| Автозапуск при включении ПК | **install_autostart.bat** (один раз) | Всё вышеперечисленное стартует само при каждом входе в Windows. |
| Убрать автозапуск | **remove_autostart.bat** | Возвращает как было. |

Детали: интервал фонового поиска — `search_every_minutes` в config.json
(минимум 15 минут — чаще нельзя, источники банят по IP). Сайт опрашивает
базу каждые 20 секунд и **добавляет** новые лиды к ленте, старые не исчезают;
дубликаты отсекаются по id из базы. Если интернета нет или Overpass лежит —
поиск просто повторится в следующий раз, сайт продолжает работать.

## Сайт на GitHub — автопилот без своего компьютера

Папка готова к загрузке в репозиторий: сайт + бот + автопоиск через GitHub Actions.

**Да, сайт будет работать на GitHub** — это обычные статические файлы, GitHub Pages
их отдаёт, а поиск там же делает GitHub Actions. Сервис работает автономно 24/7
даже когда твой компьютер выключен.

Как загрузить (5 минут):

1. Зарегистрируйся на github.com → «+» справа вверху → **New repository** →
   имя например `leadradar` → Public → Create.
2. На странице репо: **Add file → Upload files** → перетащи ВСЕ файлы и папки
   из этой папки (index.html, bot.py, cli.py, leadgen/, data/, config.json,
   .github/ и остальные) → **Commit changes**.
3. **Settings → Pages** → Source: «Deploy from a branch» → Branch: `main`,
   папка `/ (root)` → Save. Через минуту сайт живёт на
   `https://ТВОЙ_ЛОГИН.github.io/leadradar/` — с вшитыми лидами (сейчас 806),
   кнопками контактов, фильтрами и автообновлением каждые 20 секунд.
4. **Actions** уже настроены (.github/workflows): каждые 30 минут GitHub сам
   запускает поиск — 6 городов за цикл по кругу из ~118 городов СНГ. Новые
   лиды попадут в leads.json и закоммитятся — сайт обновится сам (сайт
   опрашивает базу каждые 20 секунд, у Pages кэш до 10 минут). Ручной запуск:
   вкладка Actions → «Поиск лидов» → Run workflow.

Контакты заказчиков на карточках сайта — кнопками («Написать в TG»,
«Позвонить», «Открыть контакт»). Ссылка на портфолио (portfolio_url в
config.json) автоматически вставляется в конец первого персонального
сообщения и в отклик на заявки из интернета.

Важно про токен: в config.json поле bot_token должно оставаться пустым
(`""`). Если вставляешь настоящий токен локально — не загружай config.json
на GitHub (он специально в .gitignore, чтобы токен не утёк).

Города и ниши меняются в config.json (`satellites`, `city_countries`,
`niches`): за один цикл бот проверяет `search_cities_per_cycle` городов
и идёт по списку по кругу — весь список СНГ проходится примерно за 10 часов,
и так 24/7. Способы поиска: OpenStreetMap (~30 тегов бизнесов по 7 нишам),
поиск «нужен сайт» по DuckDuckGo (14 запросов, включая t.me и vk.com),
Яндекс API при наличии ключа.

## Сайт index.html — лиды прямо в браузере

Файл `index.html` — дашборд с лидами: фильтры, поиск, приоритеты,
нейро-сообщение заказчику под каждым лидом. Данные вшиваются прямо в файл,
отдельный файл загружать не нужно:

- **Живой режим (самообновление):** двойной клик по `start_site.bat` —
  откроется сайт, который раз в 20 секунд сам проверяет базу и **добавляет**
  новые лиды к ленте (старые не исчезают). Окно сервера можно свернуть,
  но не закрывать — самообновление работает, пока окно открыто.
- **Один клик (офлайн-вариант):** запусти `update_site.bat` — он впишет всю
  базу прямо в `index.html`, дальше сайт можно открывать двойным кликом
  без сервера.
- **Автоматически:** если запущен бот (`start.bat`), он ищет лидов сразу при
  запуске и потом по расписанию утром, и после каждого поиска сам обновляет
  и `index.html`, и `leads.json`, если сайт лежит рядом с папкой бота.
- **Руками:** `python cli.py update-site [путь к index.html]`.
  Файл обновляется сколько угодно раз — старая база заменяется новой.
- **Без бота вообще:** можно перетащить файл `leads.json` (команда
  `python cli.py export-json`) прямо в окно сайта.

Если база пуста, сайт показывает демо-ленту с вымышленными контактами —
не перепутай её с реальными лидами: в шапке будет «демо».

## Если что-то не работает

- **Нажимаю /start в Telegram — бот молчит** → значит, бот просто не запущен
  (отвечать некому). Окно консоли с ботом должно быть открыто и показывать
  «✅ Бот @имя запущен и слушает сообщения». Если окна нет или оно закрылось —
  запусти `start.bat` двойным кликом (Windows) и читай, что он пишет: он
  по-русски объяснит каждую проблему — нет Python, нет интернета, неверный токен.
- **На Windows не запускай start.sh** — это скрипт для Linux/macOS, Windows
  его не исполняет. Тебе нужен `start.bat`.
- **[ОШИБКА] Python не найден** — установи Python с python.org и при установке
  поставь галочку «Add Python to PATH», потом снова запусти start.bat.
- **«❌ Нет токена бота!» / «Telegram не принял токен»** — открой config.json,
  вставь токен от @BotFather в поле bot_token (без пробелов и кавычек вокруг
  всего значения), сохрани, запусти снова.
- **«Overpass недоступен»** — сервис временно перегружен. Бот сам пробует 4
  зеркала; если все молчат, подожди 10-15 минут или добавь зеркало в
  `overpass_mirrors`. Проверка: `python cli.py doctor`.
- **Город не найден в OSM** — проверь написание в `config.json` (геокодинг
  идёт по названию через Nominatim, страна — `country_code`).
- **Хочу другой город/нишу** — правь `config.json`, перезапускай бота. Список
  тегов ниш можно расширять в `leadgen/niches.py` (это OpenStreetMap-теги).

```
  scoring.py           — скоринг «жирных» 0-100
  messages.py          — 3 варианта персонального текста + отклик на заявки
  pipeline.py          — конвейер: источники → дедуп → скоринг → база
  storage.py           — SQLite: дедуп, статусы, статистика
  export.py            — выгрузка в Excel
  niches.py            — ниши: теги OSM, веса, формулировки
fixtures/overpass_sample.json — реальный снимок данных для selftest
data/                  — база, кэш, экспорты (создаётся сама)
```
